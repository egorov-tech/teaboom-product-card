# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание: верхний блок карточки товара интернет-магазина чая.
Вёрстка без фреймворков — HTML5, SCSS, vanilla JS.

**Опубликованная страница:** https://egorov-tech.github.io/teaboom-product-card/

## Запуск

Сборка не требуется — склонировать и открыть `index.html`:

```bash
git clone https://github.com/egorov-tech/teaboom-product-card.git
cd teaboom-product-card
open index.html          # или python3 -m http.server 8000
```

Единственная внешняя загрузка — шрифты Google Fonts; без сети страница откатывается
на системный гротеск. Локальный сервер нужен, только если браузер не отдаёт WebP
с `file://`.

## Сборка стилей

Скомпилированный `assets/css/main.css` лежит в репозитории, пересобирать необязательно.

```bash
npx sass assets/scss/main.scss assets/css/main.css --no-source-map --style=expanded
```

## Что реализовано

- шапка магазина: логотип, контакты, корзина со счётчиком, меню и поиск;
- заставка при первом открытии: чайный лист прорисовывается, затем страница проявляется;
- фото товара, название, категория и хлебные крошки до неё;
- выбор из четырёх фасовок: 100, 500, 1000 и 5000 г;
- артикул, актуальная и старая цена, размер скидки — меняются вместе с фасовкой;
- цена за 100 г и выгода крупных фасовок относительно 100 г (считается из цен, не захардкожена);
- кнопка «В корзину» с состояниями hover / active / focus: копия фото улетает в корзину,
  счётчик увеличивается, кнопка подтверждает добавление;
- краткое описание и характеристики чая.

## Адаптив

Сетка построена на CSS Grid, размеры шрифтов и отступов — на `clamp()`.

| Ширина  | Раскладка |
|---------|-----------|
| ≥ 1060px | две колонки: фото слева, покупка справа, описание на всю ширину снизу |
| 600–1059px | стек, ширина фото ограничена, чтобы цена и кнопка оставались на первом экране |
| < 600px | стек на всю ширину, фасовки в две колонки, кнопка на всю ширину |
| < 420px | фасовки остаются в две колонки, минимальная зона нажатия — 76px по высоте |

Проверено в браузере на 1440, 768 и 375 px: горизонтальной прокрутки нет.

## Доступность

- фасовки — нативная radio-группа в `fieldset` с `legend`: работают стрелки и Tab;
- блок цены помечен `aria-live="polite"`, смена фасовки объявляется скринридером целиком;
- видимый фокус через `:focus-visible`, зона нажатия фасовки — 76px по высоте;
- контраст текста к фону — от 4.9:1 (минимум по WCAG AA — 4.5:1);
- меню на узких экранах прокручивается по горизонтали, а не прячется за бургер;
- при `prefers-reduced-motion: reduce` заставка не показывается, полёт в корзину
  не запускается, переходы отключаются — счётчик корзины всё равно обновляется.

## Анимации

Заставка — inline-SVG: контуры листа прорисовываются через `stroke-dasharray`, затем слой
уходит в прозрачность, а шапка и карточка всплывают. Всё на CSS-анимациях с `both`, поэтому
даже с отключённым JS заставка гарантированно исчезает. Показывается один раз за вкладку:
JS ставит флаг в `sessionStorage`, а инлайн-скрипт в `<head>` читает его до первой отрисовки,
чтобы не мигнуть заставкой на повторном заходе.

Полёт в корзину — Web Animations API: копия фото летит по дуге к иконке корзины,
после чего счётчик увеличивается с короткой пульсацией.

## SEO и семантика

- `main`, `article`, `nav` с хлебными крошками, `figure` / `figcaption`, `dl` для характеристик;
- один `h1`, описательный `title` и `meta description`, `canonical`;
- Open Graph и Twitter Card;
- JSON-LD: `Product` с `AggregateOffer` по четырём артикулам и `BreadcrumbList`;
- фото отдаётся через `<picture>` в WebP с JPEG-фолбэком, с `width` / `height` и `fetchpriority="high"`.

## Технические решения

- **Один источник данных.** Цены, артикулы и вес заданы `data`-атрибутами на
  `input[type=radio]`. JS читает их и отрисовывает и суммы в чипах, и блок цены, поэтому
  разойтись эти числа не могут. Без JS страница открывается в состоянии по умолчанию
  (100 г) и остаётся читаемой, но пересчёт при выборе другой фасовки не работает.
- **Выгода за 100 г** считается относительно самой маленькой фасовки, поэтому при смене
  прайса ничего править в разметке не нужно.
- **Демо, а не продакшен.** `canonical` указывает на боевую карточку Teaboom, а страница
  закрыта `robots: noindex` — чтобы копия не конкурировала с оригиналом в выдаче, если
  выложить её на статический хостинг.
- **Фон кремовый с фирменным паттерном** — как на teaboom.ru; фото товара снято на белом,
  поэтому оно лежит на белой панели, иначе вокруг него была бы заметная светлая рамка.
- **Без библиотек**: ни Bootstrap, ни jQuery, ни готовых шаблонов магазина.
